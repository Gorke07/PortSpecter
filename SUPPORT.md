# Support

Start with [installation](docs/INSTALLATION.md), [usage](docs/USAGE.md) and [troubleshooting](docs/TROUBLESHOOTING.md).

For bugs or usage questions, search [existing issues](https://github.com/Gorke07/PortSpecter/issues), then open an issue with the appropriate template. English and Turkish are welcome. This is a community development project; response times are not guaranteed.

Include your OS/version, CPU architecture, PortSpecter commit/version, scan method, relevant settings, expected behavior and actual behavior. For discovery issues, include the protocol and device model/firmware if available. Say whether the target is local, routed or reached over VPN.

Use synthetic addresses and redact MACs, serials, hostnames, credentials and private share names as needed. Do not upload a real SQLite database or a complete network export. Report vulnerabilities using [SECURITY.md](SECURITY.md), not a public bug report.
